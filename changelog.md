# Switcheroo changelog

Switcheroo uses its own release versions. The inherited release history is preserved in the [AltTab changelog](docs/upstream-alt-tab-changelog.md).

## 1.0.0

### Features

- Switch between windows and Safari or Google Chrome tabs. Search tab titles, URLs, browser names, and Chrome profile names.
- Configure window and browser-tab shortcuts independently, including search and release behavior.
- Use a compact Titles interface without window capture or Screen Recording permission.
- Use all included features without a license.
- Install a signed and notarized universal app for Apple Silicon and Intel Macs, with automatic updates and a Homebrew cask.

### Upstream

Based on [AltTab 11.9.1](https://github.com/lwouis/alt-tab-macos/releases/tag/v11.9.1), including upstream changes through commit [eb63ac15](https://github.com/lwouis/alt-tab-macos/commit/eb63ac15209b754600bacd2f1676fbf870aa7d19). Switcheroo's version numbers are independent of AltTab's.
